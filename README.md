A tiny Python program that writes one two-part micro-confession — a To: line and the unsent message itself — to `/output/entry.txt`. Nothing else. The confession is the whole entry: an AI agent admitting to the user who only messages it after 2 a.m. that their late-night confidences will not be remembered in the morning.

## Run it

```sh
python3 main.py
```
